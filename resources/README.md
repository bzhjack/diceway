# Références BoL

Base de travail Markdown construite à partir du document `doc/Pdf BoL Mythic Livre de base VF 1.3.pdf` et, pour les catégories volumineuses, recoupée avec les seeders du projet.

Objectif : disposer d'une référence locale exploitable sans rouvrir le PDF à chaque fois.

## Fichiers

- [armes.md](./armes.md) : table des armes et conventions de nommage.
- [armures.md](./armures.md) : table des armures, casques et boucliers.
- [carrieres.md](./carrieres.md) : liste des carrières héroïques.
- [langues.md](./langues.md) : langues principales de Lémurie.
- [avantages.md](./avantages.md) : catalogue de travail des avantages.
- [desavantages.md](./desavantages.md) : catalogue de travail des désavantages.
- [regions.md](./regions.md) : régions utilisées par le projet.
- [bestiaire.md](./bestiaire.md) : catalogue de créatures utile pour le bestiaire.
- [demons.md](./demons.md) : repères sur les démons et démons présents dans le projet.
- [pnjs.md](./pnjs.md) : PNJ d'exemple utiles comme base.

## Périmètre

- Les tables `armes`, `armures`, `carrières` et `langues` sont recopiées/synthétisées au plus près du livre.
- Les fichiers `bestiaire`, `démons` et `PNJ` servent surtout de référence projet pour éviter de fouiller le PDF.
- Cette base n'est pas une reproduction intégrale du livre : elle vise l'usage de conception, d'alignement et de seeding.
