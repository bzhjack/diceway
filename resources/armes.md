# Armes

Source principale : chapitre 2, pages 49-50 du livre.

## Catégories de dégâts

- `d6M` : arme légère.
- `d6` : arme moyenne.
- `d6B` : arme lourde.
- En mêlée, on ajoute la `vigueur`.
- À distance, on ajoute `vigueur / 2` arrondie à l'inférieur.

## Conventions utiles pour le projet

- Si le projet a besoin d'un nom d'usage plus précis, le rattacher à sa ligne BoL de base.
- Exemples :
  - `Sabre`, `Tulwar`, `Cimeterre` -> `Épée`
  - `Kriss`, `Poignard`, `Coutelas`, `Couteau` -> `Dague`
  - `Khastok` -> `Arme d’hast`
  - `Bâton-fronde` -> `Fronde / bâton-fronde`
  - `Fléchette` -> `Javelot / fléchette`
