# Cyberpunk RED

Édition française d'Arkhane Asylum (2021). En cours de modélisation. Même découpage que `../bol/` (voir `../README.md`) : créer les sous-dossiers au fur et à mesure.

| Dossier | Contenu |
| --- | --- |
| `pdf/` | Les PDF d'origine. Hors git : à copier à la main sur chaque poste. |
| `pdf-text/` | Texte extrait du livre de base, un fichier par chapitre (page PDF = page livre + 4). Voir son README. |
| `rules/` | Règles mécaniques en neuf fiches, de la création au netrunning et à l'économie. Commencer par `00-index.md`. |
| `resources/` | Données de référence (armes, cyberware, rôles, compétences…). |
| `specs/` | Ce que l'application doit respecter à la création des fiches. |
| `plans/` | Notes de travail datées sur la partie Cyberpunk de l'application. |
