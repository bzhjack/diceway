# Générateur de Marché de nuit

Pages source : p. 337-340. Règles : `../rules/09-economie.md`.

1. Lancer deux fois `1d6` (relancer un doublon) : les deux types de produits du marché.
2. Pour chaque type, `1d10` : le nombre d'articles différents.
3. Tirer chaque article au `d100` (deux d10, dizaines puis unités) dans la colonne du type ; relancer les doublons. Un article proposé en plusieurs qualités est présent dans toutes.

| 1d6 | Type | Remarque |
| --- | --- | --- |
| 1 | Nourriture et drogues | |
| 2 | Électronique personnelle | parfois un GLACE Noir sur les étals louches |
| 3 | Armes et protections | |
| 4 | Cybermatériel | la pièce mère nécessaire est aussi en vente ; pose gratuite chez le charcudoc du vendeur |
| 5 | Vêtements et cyberfashion | la cyberfashion se pose sur place |
| 6 | Équipement de survie | |

**Marché de minuit** (Fixer de rang 9+, sur invitation) : `1d10 + 5` objets rares choisis par le MJ ; les huiles du crime y traitent leurs affaires et recrutent.
