# Cybermatériel

Pages source : p. 358-366 (catalogue complet du Marché de nuit) ; résumé p. 110-117. Règles (pose, emplacements, Humanité, cyberpsychose) : `../rules/06-cybermateriel-et-humanite.md`.

- **Pose** : boutique, centre médical ou hôpital ; elle est comprise dans le prix. « Non concerné » : une puce, qui se glisse dans un support de puces.
- **PH** : valeur fixe à la création, dés entre parenthèses ensuite. `1d6/2` s'arrondit au supérieur.
- Chaque élément occupe **un emplacement** de sa pièce mère, sauf mention. Les bonus d'un même modèle ne se cumulent pas, sauf mention.
- Options « couplées » : achetées et posées sur les deux yeux ou les deux jambes, PH payée pour chacune.
