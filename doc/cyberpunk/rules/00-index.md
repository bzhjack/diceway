# Cyberpunk RED — Corpus mécanique

Source : livre de base, édition française d'Arkhane Asylum (2021), `doc/cyberpunk/pdf/Cyberpunk RED - Livre de base VF.pdf`. Texte extrait dans `doc/cyberpunk/pdf-text/` (un fichier par chapitre).

Objectif de ce dossier :

- Ne garder que les mécanismes exploitables en jeu ou en implémentation.
- Laisser de côté la fiction, l'histoire du monde, la description de Night City et les conseils de MJ sans règle.
- Laisser les catalogues longs (profils de CARAC, équipement de départ, Marché de nuit, PNJ, parcours) à `../resources/`, avec ici seulement ce qu'il faut pour comprendre les règles.

## Abréviations

`CARAC` caractéristique ; `INT` Intelligence, `RÉF` Réflexes, `DEX` Dextérité, `TECH` Technique, `PRES` Prestance, `VOL` Volonté, `CHA` Chance, `MOUV` Mouvement, `COR` Corps, `EMP` Empathie ; `SD` seuil de difficulté ; `PS` points de santé ; `PA` pouvoir d'arrêt ; `PDS` points de dégâts structurels ; `PH` perte d'Humanité ; `PAM` points d'amélioration ; `ED` eurodollar ; `REZ` points de vie d'un programme.

## Convention

- Les noms de règles sont ceux de la VF ; les formulations sont paraphrasées.
- Le tableau de base : `CARAC + compétence + 1d10`, contre un SD ou en opposition, et il faut **dépasser** (l'égalité profite au défenseur).
- Ce qui est incertain, contradictoire dans la VF ou laissé au MJ est signalé dans le fichier concerné. Deux points ont été tranchés le
  2026-11-06 pour l'application (implants de départ du Solo, garage du Nomade au rang 4) : voir `../plans/2026-11-06-architecture-multi-jeu.md`.

Les tables de ces fiches ont été vérifiées contre la mise en page du PDF quand l'extraction brute mélangeait les colonnes : portées, blessures critiques, implants de départ, drones, points d'amélioration.
