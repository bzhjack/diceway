# Armes

Source principale : chapitre 2, pages 49-50 du livre, avec la mise à jour Mythic+ (`doc/pdf-text/07-maj-mythic-plus.txt`).

## Catégories de dégâts

- `d6M` : arme légère.
- `d6` : arme moyenne.
- `d6B` : arme lourde.
- `d6 ou d6B` (Mythic+) : arme maniée à une main (`d6`) ou à deux mains (`d6B`).
- En mêlée, on ajoute la `vigueur`.
- À distance, on ajoute `vigueur / 2` arrondie à l'inférieur.

## Armes régionales (Mythic+)

Elles se rencontrent rarement entre les mains d'un étranger (acquise à prix d'or, pillée…), ce qui lui vaut la réprobation des gens
du cru. Seul un héros de même origine régionale peut en faire son arme favorite.

## Conventions utiles pour le projet

- Si le projet a besoin d'un nom d'usage plus précis, le rattacher à sa ligne BoL de base.
- Exemples :
  - `Sabre`, `Tulwar`, `Cimeterre` -> `Épée`
  - `Poignard`, `Coutelas`, `Couteau` -> `Dague` (le `Kriss` est une arme à part depuis Mythic+)
  - `Bâton-fronde` -> `Fronde / bâton-fronde`
  - `Fléchette` -> `Javelot / fléchette`
