# Démons

Source principale : chapitre 5, sections `Les démons` et `Table de création des démons`.

## Rappels utiles

- Le livre distingue plusieurs catégories de démons.
- Le projet dispose déjà d'un petit socle de démons seedés, utile comme base de test et de bibliothèque.
- Les pouvoirs démoniaques structurent davantage l'identité d'un démon que son seul nom.

## Démons actuellement présents dans le projet

- Zullthegg
- Vul’mazzanlu, la chose singe
- Mazallakos le Voilé

## Utilisation

- Se référer à `backend/database/seeders/BolDemonSeeder.php` pour les stats et pouvoirs.
- Utiliser ce fichier comme index rapide des entrées déjà disponibles.
