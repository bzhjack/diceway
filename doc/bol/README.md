# Barbarians of Lemuria (Mythic)

| Dossier | Contenu |
| --- | --- |
| `resources/` | Données de référence du jeu (armes, armures, carrières, langues, avantages, désavantages, régions, bestiaire, démons, PNJ). À consulter en premier. |
| `rules/` | Règles mécaniques par chapitre du livre (`00-index.md`), exemples de jets, et l'aide de jeu pour la table (`aide-de-jeu.md`). |
| `pdf-text/` | Texte extrait des PDF du livre, un fichier par chapitre : pour vérifier une règle sans rouvrir le PDF. |
| `pdf/` | Les PDF d'origine (livre de base, mise à jour Mythic+, suppléments). Hors git : à copier à la main sur chaque poste. |
| `specs/` | Ce que l'application doit respecter à la création d'un héros, d'une créature ou d'un démon. |
| `scenarios/` | Une saga par dossier : transcription du supplément, fiches de session par chapitre, et `app/` pour les fichiers d'import (format : `scenarios/format-import.md`). |
| `image-prompts/` | Prompts des bannières de bibliothèque et des portraits du catalogue (PNJ, créatures, démons). Ceux des fiches d'une saga sont dans `scenarios/<saga>/portraits.md`. |
| `plans/` | Notes de travail datées sur l'application : états des lieux, revues de code, reste à faire. |
